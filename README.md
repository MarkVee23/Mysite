## 📌 關於專案 (About This Project)

這是我的個人專業履歷與作品集網站，採用 **高質感暗色調與玻璃擬物風格 (Glassmorphism)** 設計，具備完美的響應式排版（手機與桌機適配）、即時背景音樂控制、燈箱預覽模式，並直接串接 **Google Apps Script (GAS) 與 Google 試算表**，實現無伺服器聯絡表單後端。

本專案同時內建完整的 **SEO / GEO / AEO (搜尋引擎與 AI 語意搜尋優化)** 架構（含 `Person` 與 `FAQPage` JSON-LD 結構化資料），確保 Perplexity、ChatGPT、Gemini 等 AI 搜尋引擎與傳統搜尋工具能精準抓取與索引個人專業定位。

## 💻 專案架構與技術亮點 (Tech Stack & Architecture)
本履歷網站採用極致效能的單一檔案架構 (Single-Page Application)，便於快速部署與維護：
* **Frontend**: HTML5, Tailwind CSS (CDN), Vanilla JavaScript。
* **UI/UX Design**: 暗黑科技風格 (Dark Mode) 搭配玻璃擬物風格 (Glassmorphism Cards)。
* **Backend Integration**: 串接 **Google Apps Script (GAS)** Web App，無縫將訪客聯絡表單資料非同步寫入 Google 試算表（具備 `@OnlyCurrentDoc` 最小權限與 CORS 容錯處理）。
* **SEO / GEO / AEO 優化**: 完整導入 `Person` 與 `FAQPage` JSON-LD 結構化資料，便於 Perplexity、ChatGPT 等 AI 搜尋引擎精準抓取。
* **多媒體與互動**: 內建背景音樂控制播放器與作品集燈箱放大檢視 (Lightbox Modal)。
